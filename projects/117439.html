Project Description

The Orion Automation Monitoring Application (OAMA) and Situation Awareness Tool proposal is a dynamic application designed to track and display what the spacecraft’s automation is doing, and in-so-far-as-possible predict the future path and decision points the automation will take. Previous vehicle automation findings, from CST-100, highlight that successful human-automation integration hinges on a clear understanding of the inputs and decisions that lead to automated actions and an ability to predict the future based on the current state. Predicting the future is necessary for the Mission Control (MCC) to work with the automated system rather than over or around it. This project will develop, test, certify, and deliver a visually rich and fully interactive application that allows MCC to examine the current state, and view both the current future, and potential alternative futures using the Artemis/Orion II mission as a testbed. FOD is planning investments beyond the IR&D phase to mature capability for Gateway, Lander, and Lunar Surface Systems relying on automation and autonomy,

Anticipated Benefits & Mission Applications

ADP Phase 1 [#2]: Multi-vehicle infometrics & information management strategy (mission and fault management) NASA's lunar exploration efforts consist of three highly automated spacecraft (Orion, Gateway, and Lander). This project would help ensure the that each vehicle's automated systems are working in concert and MCC is fully aware of the information driving automated actions. The proposed display integrates that swath of information in a dynamic/transparent visual and addresses: ADP Phase 1 [#15]: Automation for dormancy / crew return assist - Monitoring automated system performance during dormancy is critical to ensure the spacecraft is taking appropriate actions to sustain long term-heath. A display of the inputs and actions is a clear method to visualize the system without the need for time consuming, opaque, and bandwidth intensive examinations of raw machine data.
