Developing a Verification and Validation Optimization Methodology with Uncertainty Quantification

NASA TechPort Project ID: 118291
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

This research aims to develop a method and software platform for using model-based system engineering principles to increase the efficiency of a project integration and testing phase. The software will use MagicDraw to implement SysML models of a system, and interface those models with subsystem simulations, in order to automatically verify formal requirements. This tool will provide a flexible framework for project engineers to evaluate additional constraints that may arise, and explore alternative system designs. This method will be tested for efficacy in multiple space science domains. The work will advance NASA's systems engineering capabilities through case studies of a generally-applicable tool.
