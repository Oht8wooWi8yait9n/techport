Swab-to-Sequence: Real-time Data Analysis Platform for the Biomolecule Sequencer

NASA TechPort Project ID: 93198
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

DNA was successfully sequenced on the ISS in 2016, but the DNA sequenced was prepared on the ground. With FY'16 IRAD funds, the same team developed a swab-to-sequencer process for the generation of sequence-ready DNA from environmental samples and demonstrated this process during the NEEMO 21 mission. Additionally, the team has already transitioned key aspects of this process to the ISS as part of the Genes in Space-3 (GiS3) payload. GiS3 has already confirmed the ability to prepare DNA for sequencing in the microgravity environment of space. While these methods continue to be tested on the ISS, a key aspect of this process yet to be developed is a software package to allow for in-flight data analysis. We will leverage software developed for a DOD-funded biosurveillance program and create a customized graphical-user-interface (GUI), offering point-and-click loading of data, parameter adjusting, and launching of analysis with simplistic visualization of results to allow for real-time microbial assessments of the environment.

Anticipated Benefits & Mission Applications

This technology will benefit a wide range of users. The entire sample-to-answer process will be able to be completed in-flight (or in any environment), and this technology will be available to a wide range of potential users. NASA will specifically benefit, as microbial contamination data will be available in real time and therefore actionable. It is anticipated that other government agencies will adopt this process to support Nanopore sequencing workflows, as NASA is already sharing sample preparation methods with them (for example the CDC).

  • Closed Out: Next-generation DNA sequencing has been deployed in the field to aid in infectious disease diagnostics, environmental monitoring, and various human health assessments. While portable sequencing technology is commercially available and sample preparation processes developed (by NASA JSC), the ability to rapidly analyze sequence data remains a bottle neck. Many laboratories use custom in-house pipelines that require internet connectivity. Additionally, these custom data analysis platforms lack oversight and regulation - key for human diagnostics. A simple to use software package capable of providing real-time actionable results from complex next-generation sequencing data is critical toward employing the power of sequencing-based diagnostics. To that end, NASA is leveraging a DoD funded effort to develop a standard and regulated open-source software pipeline for pathogen diagnostics from next-generation sequencing data. The software in development, PanGIA, is specifically for Illumina sequence data. NASA uses the MinION sequencer - which produces Nanopore sequence data. NASA, in collaboration with MRIGlobal, has modified the software to support Nanopore sequence data. Additionally, work toward NASA specific graphical-user-interface requirements, parameter adjusting, launching of analysis, and visualization of results has been completed. Nanopore sequence data obtained from ISS sequencing runs has been successfully assessed with the PanGIA pipeline. NASA will seek AES LSS funds to further development specific for spaceflight needs.
