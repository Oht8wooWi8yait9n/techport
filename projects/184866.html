Surface Power Exchange Vehicle Interface

NASA TechPort Project ID: 184866
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

The Surface Element Power Exchange Vehicle Interface project is establishing a unified, bidirectional 6kW (120 V, 50 A) power interface for all lunar and future Martian surface elements. This standard interface will enable any surface assets—such as habitats, rovers, power plants, or technology payloads—to exchange power with other elements, sources, or loads through a common interface.

The project scope includes defining functions, requirements, and attributes, that mature the development of a standardized power interface that supports safe and reliable bidirectional power flow while meeting existing space power standards and lunar power specifications. This effort includes drafting an interface requirements document, incorporating industry feedback, producing an interface control document, and supporting verification of the finalized power interface.

By standardizing this power exchange interface across all surface systems, the project will ensure interoperability, reduce integration complexity, and streamline logistics for sustained lunar—and eventually Martian—surface operations.

Anticipated Benefits & Mission Applications

This project will deliver a standardized power exchange interface for all Artemis surface elements, enabling any element to safely send or receive power from another. By providing comprehensive design specifications through an Interface Requirements Document and Interface Control Document, the project allows Moon‑to‑Mars programs, international partners, and commercial vendors to design hardware to a common set of specifications, improving interoperability, reducing integration risk, and simplifying end‑to‑end system planning.

Key technical considerations and performance parameters include:

  •  Electrical Isolation: The interface will support configurable isolation between EPS and EPCE supply and return conductors to prevent circulating AC or DC currents and mitigate stability concerns when multiple sources and loads operate in parallel. Isolation levels will meet or exceed 1 MΩ at the hardware level, ensuring that a fault in one branch of the EPS or EPCE does not disable the other source.
  •  Distribution Wiring: The interface will implement a two‑wire power distribution system with a dedicated return conductor, maintaining a distributed single‑point ground and preventing intentional current flow through spacecraft structure. Parallel wiring for current sharing remains compatible, and minimizing conductor spacing is recommended to reduce inductance.
  • Single‑Point Ground: Grounding architecture will be coordinated closely with Moon‑to‑Mars programs to ensure compliance and compatibility across all participating systems.
  • Autonomous functions using Robotics technology: The connector system will support the use of robotics technology to help the manipulation and mate / de-mate of the surface power connector system between two vehicles.
