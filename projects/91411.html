A Field Programmable Gate Array (FPGA) -based, Radiation Tolerant, Reconfigurable Computer System with Real Time Fault Detection, Avoidance and Repair Testing

Project Description

The goal of this project is to mature the technology readiness level of a radiation tolerant, reconfigurable computer system that has been developed at Montana State University (MSU). The improved radiation tolerance delivered by our approach makes reconfigurable computing using commercial FPGA fabrics a reality.

Anticipated Benefits & Mission Applications

This novel computer system uses a variety of fault mitigation techniques to provide increased reliability in harsh radiation environments and will benefit the commercial space industry and future NASA missions.
