Space Grade Linux for Facilitating Open Source Industry Collaboration

NASA TechPort Project ID: 157204
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

Introduces first class Linux support for flight software in next-generation space processors and allows missions to tap into Linux's unrivaled performance, hardware support, and software ecosystem. This support is enabled through an embedded linux distribution using the Yocto Project named Space Grade Linux, Linux-specific core Flight System apps, and other general operating system components.

Anticipated Benefits & Mission Applications

  • Offers a reusable software ecosystem reducing the need to "reinvent the wheel".
  • Reduces required level of technical expertise to develop flight software.
  • Facilitates integration of modern software frameworks, such as for AI/ML, into flight software running on modern space processors.
  • Establishes a reference operating system on which flight software and next generation space processors can target.
  • If desired, enables future collaboration among industry, academia, and large open source non-profit entities that can revolutionize the software and hardware ecosystem for space to pronounced effect Automotive Grade Linux project had on the Automotive industry.

Technology Transition & Outcomes

  • Closed Out: By combining new or improved software interfaces and tooling with heritage flight software frameworks, this project has significantly advanced our ability to leverage Linux technologies to deploy flight software and has laid the foundation to effectively collaborate and participate in related open-source development. With this, many missions expect to see a reduction in bespoke software and cost to develop software. Throughout this project, future collaboration opportunities and partnerships were identified and pursued for non-sensitive open-source software, enabling NASA to share the cost of common components. In many cases, development of Linux technologies enabled by this project are expected to benefit industries beyond space. Efforts are underway to make open-source contributions developed under this project as integrated flight software frameworks rapidly evolve. The completion of a project does not necessarily indicate that the development work has stopped. The work could potentially continue in the future as a follow-on IRAD; or be used in collaboration or partnership with Academia, Industry, and other Government Agencies. Goddard Space Flight Center’s IRAD program is managed under its Office of Chief Technologist. Activities develop concepts, reduce technology risk, and advance human capital and technological capabilities. Goddard’s IRAD program is highly competitive, opportunity-driven, and 100% strategically aligned with NASA's and Goddard's strategic priorities. A significant portion of the program is focused on Early Stage Innovations for high-risk, strategically aligned, potential high-payoff technologies that are longer-term or lower TRL.
