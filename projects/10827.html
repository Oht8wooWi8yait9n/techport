Optimization of Onboard Processing Using the Maestro Multicore Processor for Decadal Missions

NASA TechPort Project ID: 10827
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

Extend Tilera testbed string to include more relevant components such as standalone disk storage Add more layers of onboard data processing chain computation to create rapid data products as will be required on space missions such as atmospheric correction. Extend work on automatic parallelization of code to make use of multiple processor and increase throughput. GSFC Collaborators: Jonathan Wilmot Twanda Jacobs Vuong Ly Matt Handy Vightel Inc: Pat Cappelaere ISI: Steve Crago
