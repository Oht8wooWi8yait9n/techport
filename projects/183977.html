Joint Observations Integrated Network : Modular software components to support the DOME's multi-mission data processing needs (JOIN)

Project Description

This project supports Goddard ESD's DOME approach, advances GSFC 2040 Vector 3's vision for pioneering data integration and supports a more integrated and efficient approach to Earth science and mission operations. We aim to overcome challenges posed by data heterogeneity and disaggregation to enable more comprehensive scientific understanding and support advanced mission concepts. To do this, we propose to develop the Joint Observations Integrated Network (JOIN), a software system for combining disaggregated space, air, and ground datasets into cohesive analysis-ready collections on-demand. Although JOIN will be designed to eventually ingest any space, air and/ or ground data from any scientific discipline, we focus our year 1 technology demonstration on a Passive-Active Near-real Time ARchitecture for Earth Planetary Boundary Layer (PBL) Sounding (PANTA REI) and a distributed Snow Water Equivalent (SWE) mission concept. We plan to expand to other Earth Science disciplines and Heliophysics in years 2 and 3.

Anticipated Benefits & Mission Applications

Builds generic system for efficiently finding, aggregating, and collocating data on-demand from decoupled constellations; Creates cloud-native processing framework for multi-mission data integration; Develops distributed snow mission concept and PBL height retrievals using integrated datasets
