Developing the Machinery for in-situ Data-Driven Simulations

NASA TechPort Project ID: 157684
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

This project enables code development necessary for simulations to be directly driven with in-situ data on a satellite track inside numerical simulation. Doing so is essential to the process of using the wealth of data from an increasing network of satellite assets to constrain space weather forecasting, and to the process of theory providing feedback informing science measurement requirements and instrument performance requirements for future mission development. This project builds on the magnetohydrodynamics characteristics-based method of data driving developed in Tarr, Kee, Linton, Schuck, & Leake (2024). At the end of this effort, we will have adapted this method to be able to directly drive a numerical simulation in a fully three-dimensional way using data provided on a satellite track traversing the interior of a computational domain.

Anticipated Benefits & Mission Applications

The method we utilize preferences the simulation's underlying equations of magnetohydrodynamics over the sometimes uncertain or incomplete time series of observations when the two do not agree. Doing so accounts for error bars on the observational data and a lower cadence of observations than typical timescales in the simulation. This allows for an a posteriori test on the degree to which the observational error bars and data cadence have influenced the results of the numerical simulations. Therefore, comparing the input data and the output of the simulation opens a more direct pathway for modeling to define scientific measurement and instrumentation performance requirements for future NASA missions.

Technology Transition & Outcomes

  • Closed Out: This project resulted in the successful development of the proposed code. The current implementation is able to inject information about the satellite state in all directions in the numerical grid. This implementation is also able to move the location of data injection, the proxy for the location of satellite measurements, through the simulation interior on an arbitrary trajectory. This implementation of a physically self-consistent data injection method will be highly complementary to existing data assimilation methods to fully leverage NASA’s satellite assets to constrain space weather forecasting. The completion of a project does not necessarily indicate that the development work has stopped. The work could potentially continue in the future as a follow-on IRAD; or be used in collaboration or partnership with Academia, Industry, and other Government Agencies.
