Project Description

This proposal presents the advantages of cognitive radar as it relates to atmospheric sensing in general, and then specifically to small satellite design for atmospheric sensing. A cognitive radar system is one that is able to optimize its parameters in real-time based upon past conditions, current conditions as interpreted from the radar return, any external information available, and an internal prediction of the future conditions of the observed environment [1]. Such an approach would improve upon existing systems because it is able to autonomously adapt to changing operational conditions and therefore always operate at maximum efficiency. Atmospheric sensors operate in conditions that can change rapidly ([2],[4]) and therefore would generate data more efficiently if they were able to react to those conditions in real-time. Small satellites, especially those adhering to the CubeSat standard, are required to operate within extremely restrictive power constraints ([5],[7],[8]). In order to advance the state of the art in cognitive radar for remote sensing on small satellites, I propose to demonstrate a fully adaptive radar system that would be constrained under the SWaP requirements of a 6U-CubeSat using a cloud profiling application and a SAR application. This would require refining the current fully adaptive radar (FAR) framework in [1] and applying it to the stated applications. Technology Transition & Outcomes

  • Closed Out: The original goal of the research was to provide proof of concept for an adaptive cloud profiling radar capable of flying aboard a 6U CubeSat via producing the control algorithm necessary to operate the sensor and a functional prototype taking SWaP constraints into account. The actual research progress covered the first goal of producing the theoretical control algorithm necessary to operate and process data from an adaptive remote sensor capable of both PRF adaptation and measurement rejection based on anticipated measurement quality, but neither a prototype nor a design specification was able to be produced. A fully documented Matlab simulation has been produced modelling a proposed adaptive cloud profiling radar system, however, that proves sensor adaptation via measurement rejection can save up to 50% of expended system resources depending upon the user’s tolerance for measurement quality. The algorithm trades off resource usage for measurement sensitivity, meaning that particularly weak measurements are discarded in favor of taking more measurements across the globe of stronger cloud structures. The thesis resulting from this work justifies further investigation on this topic, and the source code for the Matlab simulation is available upon request.
