Head/Body Monitor (HBM)

NASA TechPort Project ID: 184933
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio

Project Description

Exploration class missions will require crew to be able to self-assess and treat their sensorimotor dysfunction after gravity transitions to accomplish operational tasks. To quantify crewmember’s adaptation following gravitational transitions and to inform when countermeasures may be needed, we must explore, develop, and validate unobtrusive monitoring tools (Monitoring Tools), define sensorimotor performance metrics (Metrics of Performance), and explore capabilities to enhance sensorimotor assessment tasks for operational use and validate functional tasks via high-fidelity analogs (Operational Assessments).

The following project focuses on the development and validation of two distinct technologies: (1) a ground-based motion capture tool to monitor sensorimotor rehabilitation to be utilized for return to duty assessments preflight and following return to Earth and (2) an exploration motion capture tool to monitor sensorimotor alterations in-flight following gravity transitions to be used for in-mission assessments for operations, e.g., exercise evaluation or sensorimotor assessments prior to early surface activities. The reason to separate out these use cases is that assessments on Earth will be able to use the latest technology with multiple cameras, while the in-mission use case will be constrained by number of cameras and in-mission processing technology available and the capture volume. The ground-based motion capture system serves as the foundation for developing the requirements for the exploration motion capture tool intended for Mars missions. This exploration tool is designed to be self-administered, enabling astronauts to independently track, analyze, and monitor their adaptation during periods of sensorimotor disruption following gravity transitions. Lessons learned and enhancements achieved while refining the ground-based system will be directly applied to the exploration tool, helping bridge the gap between current capabilities and the key performance parameters defined for the project’s end state.

Anticipated Benefits & Mission Applications

These efforts will boost the reliability of sensorimotor capabilities for landing and post-landing activities. Specifically, they aim to provide crewmembers with the monitoring and assessment tools needed to evaluate readiness for mission operations inflight as well as rehabilitate postflight. These capabilities will enable successful crew performance of exploration mission objectives.

Technology Transition & Outcomes

  • Transitioned From: Sensorimotor Countermeasures transitioned from a single project to multiple projects in Oct 2025.
  • Canceled: With the dissolution of the Mars Campaign Office Program, the Head Body Monitoring project was cancelled. The project team hopes that elements of the project will be picked up / absorbed into other projects.
