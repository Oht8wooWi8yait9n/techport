Project Description

The Regolith Advanced Surface Systems Operations Robot (RASSOR) is an advanced excavation robot designed to mine and deliver lunar regolith for In Situ Resource Utilization (ISRU) processing. RASSOR’s unique design enables it to efficiently collect regolith, excavate trenches, build landing pads and berms, return collected regolith for processing, and myriad related ISRU activities. To reliably perform these operations in the harsh lunar environment, RASSOR software and sensory systems need to be robust, adapt to uncertainty, and make informed decisions with limited sensory information. Currently, RASSOR lacks the ability to estimate collected regolith mass, and digging controllers are inefficient and not robust to variable compactness and contents of sub-surface regolith. Practically, this means that RASSOR’s autonomous digging routines need to be optimized to handle this variable compactness, infer weights from available sensor data, and optimize power savings to increase runtime. Traditional modelling and control approaches have proved challenging due to system complexity. As such, this project seeks to acquire and optimize this information through application of robust machine learning (ML) models and computer vision tools.

Anticipated Benefits & Mission Applications

The ICE-RASSOR team applied ML to solve an existing technical challenge faced by ISRU researchers in Swamp Works: How to enable the RASSOR excavation robot to execute autonomous lunar ISRU missions. This project infused ML skills into the KSC technical workforce, enabling KSC engineers and scientists to use ML tools and techniques to solve extremely complex problems across the Center.

Technology Transition & Outcomes

  • Closed Out: The ICE-RASSOR team applied machine learning (ML) to solve an existing technical challenge faced by ISRU researchers in Swamp Works: How to enable the RASSOR excavation robot to execute autonomous lunar ISRU missions. This project infused ML skills into the KSC technical workforce, enabling KSC engineers and scientists to use ML tools and techniques to solve extremely complex problems across the Center. The team developed a computer simulation of the regolith test bed inside the Big Bin in Swamp Works. Initially, the Gazebo open-source simulation was pursued as it tightly integrated with existing control software and models used on the real RASSOR system and would leverage existing models, lunar landscape scenes, and models of Big Bin. However, as Gazebo lacks mechanisms to simulate soil interaction, a 2D simulation was instead developed from scratch. The 2D simulation served to prototype learning algorithms for excavation optimization through reinforcement learning which were later applied in a more comprehensive 3D simulation developed using the Unity simulation engine. The fidelity of the 3D simulation enables a wide range of new capabilities, including the development and training of additional sensing capabilities and research both at the granular mechanics and operations levels. Drum mass inference enables RASSOR to decide when to exit digging/dumping routines and mobilize to the next operation, thereby increasing transition efficiency and saving power. With increased mass estimation resolution, RASSOR will also perform construction tasks with the capacity to loosely regulate soil flow rates. During testing in the ‘Big Bin’, RASSOR can be instructed to dig in novel positions and record the sensor data. This data will be used to train a neural network to internalize a relationship between position/torque sensor values and known regolith masses. The learned model will then predict masses based on real-time sensor readings. Two different motor current sensing methods were tested. The first method used the motor current values in the arms. This data was collected prior to COVID-19 mandatory telework during 2020. The second method used data collected during 2021. This method used average motor current values of the drum motors instead of the arms. The newer drum-based method was found to be more versatile. The core idea of reinforcement learning is to enable a simulated entity called the agent to learn a task strategy by performing actions and sensing rewards. When these actions are performed, it results in a change of state to the environment, and a quantitative reward is returned which informs the agent whether the action it performed was good or not. In the case of ICE-RASSOR, the agent is the robot and the actions are movements of the robot’s actuators. Sensing is done via pseudo sensors which track the environment. Finally, the reward function is specified by the machine learning engineer to encourage the agent to learn a desirable strategy. The agent’s goal (ICE-RASSOR) is to learn an excavation strategy by exploring actions, sensing and storing the resulting state and reward, and selecting actions that maximize its reward. There are several reinforcement learning algorithms which can be used to acquire these behaviors and measure the quality (also called utility) of being in a state. Some considerations include balancing exploration and exploitation: how often does an agent try new actions versus applying knowledge it has already gained; tuning various learning parameters; and different state and action representations. An excavation policy could not be executed on the physical system due to limited access to labs during the COVID-19 lockdown, hardware failures (RASSOR arms issues, battery replacements, and camera issues), and pending sensor installations. To realize the physical execution of a learned control policy requires additional software development effort for RASSOR and the installment of additional tracking and vision cameras.
