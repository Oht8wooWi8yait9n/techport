AI/ML-assisted Universal Discovery in Roman Light Curves

NASA TechPort Project ID: 157206
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

The primary obstacle to the exploitation of science from optical light curve survey data is the researcher’s ability to find a light curve containing the astrophysical signal in which they are interested from among tens to hundreds of millions of light curves. This obstacle will only grow as the size of light curve data sets is augmented by improved observatories, such as the Nancy Grace Roman Space Telescope (Roman). As such, we propose to develop a universally-applicable machine learning framework for the purpose of finding any known and/or predicted astrophysical signal present in Roman light curves. This pipeline will allow a user to input a theoretical signal, which will be injected on a pre-collected set of template light curves designed to account for noise and systematics. This process will create “mock data” which will then be used to train a pre-constructed neural network, needing only minimal training due to transfer learning from pre-trained weights, to classify the astrophysical signal.

Anticipated Benefits & Mission Applications

Accessibility to open data implies access to the value beneath the raw data, which can often be unobtainable to those without the capability to comb large data sets. By allowing any researcher to use AI/ML to make discoveries in Roman data, we intend to remove this obstacle. This effort will be truly community-serving. Our team is uniquely positioned to bring expertise in AI/ML combined with an extensive knowledge of various astrophysical signals in order to design and test a software package that will provide an enduring community benefit and improve the science yield of Roman.

Technology Transition & Outcomes

  • Closed Out: The project was successful in achieving the stated objectives. We created several million synthetic Roman light curves with many different types of modeled stellar variability. We then developed and trained an autoencoder neural network to identify latent features in the light curves and, replacing the decoder with a classification-type neural network, demonstrated the effectiveness of using the encoder as a foundation for fast training of an adaptable classifier. The structure and pre-trained weights of the neural network can now be used for implementation in a community-serving code to discover user-defined signals from among Roman light curves upon their release.   • Example neural network schematic — Example neural network schematic. The light curve first passes through an attention layer, which learns through training to identify the most important aspects of the light curve for classification. After this, the light curve repeatedly undergoes convolutions with kernel weights learned through training. Activation is normalized to control the gradient, and dropout layers, which remove random neurons to generalize the signal classification, are interspersed throughout the network. Residuals skip layers in order to maintain relevant information to the classification rather than filter it.
