Regolith Valve Development (RVD)

NASA TechPort Project ID: 147019
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

Develop valves and valve specifications for extended operations for In-Situ propellant and consumables production including oxygen from regolith and water from icy regolith.



Anticipated Benefits & Mission Applications

Provide technical results as to which valves and what type can be used with lunar regolith and identify how long the valve can be used before failure. Potentially create innovative valves for use with lunar regolith.
