Model Based Systems Engineering Architecture Library Challenge

NASA TechPort Project ID: 117546
Official NASA Source: Space Technology Mission Directorate (STMD) TechPort Portfolio
View Official Project on NASA TechPort →

Project Description

This was a pilot challenge to find creative space architecture representations and system decomposition using SysML elements for a Model-Based Systems Engineering (MBSE) library.

Mission architects mostly start from scratch to build model elements representing the functional and physical architecture of a system in SysML. There are a few beginning libraries, but these are also local to a program or group.

NASA mission architects need a library of SysML elements for common physical and functional elements that is consistent across NASA. This prize contest open to individuals as well as university students to create a habitat-related architecture library of model elements. Develop Model-Based System Engineering models of planned space architectures using SysML. We are looking for novel and optimal model structures and representations that will allow for clear and effective use of those models in the systems engineering process.

Anticipated Benefits & Mission Applications

Developing a common library of model elements will save system engineers a large amount of time, will allow project stakeholders to recognize common graphics and quickly understand the architecture options. This project spurred discussion of libraries, profiles, meta-modeling, and model validation. This challenge increased engagement and visibility for NASA across systems engineering field and space industry, and provided NASA with visibility and connections to potential future workforce.
