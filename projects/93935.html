Project Description

The HET project is advancing technologies required for a remotely operated robotic free flyer on the International Space Station (ISS). ISS testing with the Smartphone on SPHERES allows the technology to be tested in a prototype system in a high fidelity, relevant environment. Current testing is focused on vision based navigation that will allow a free flyer to navigate anywhere within the ISS. Prior to the parabolic flight, the Smartphone vision based navigation had only performed in 1g. The parabolic flight tests have allowed the technology to be tested in a medium fidelity, relevant environment. Though the parabolic flight tests are performed in 0g, the parabolas don’t last as long as the robotic tasks would, and therefore cannot test long-term drift in the localization.

Anticipated Benefits & Mission Applications

This technology will enable free fliers to move around autonomously in the ISS to assist crew members during intra vehicular activity, thus benefiting future ISS missions by providing a helpful tool to enhance productivity.
